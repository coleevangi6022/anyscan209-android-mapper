## Overview

AnyScan209 brings geophysical survey organization and interpretation to Android devices. It provides live 2D and 3D views of subsurface scan information, allowing survey results, anomaly distributions, and stratigraphic data to be reviewed in the field.

Readings may come from the device's integrated magnetometer or from compatible external equipment connected through Bluetooth. The application also includes project management, configurable scan grids, color-based map display, database storage, and export functionality for mineral exploration and related mapping work.

## Capabilities

- View subsurface scan readings in real time through a 2D display
- Examine maps and survey results with 3D rendering
- Collect data using an Android phone's built-in magnetometer
- Use compatible external sensors over Bluetooth

- Display anomalies with color-coded map layers
- Configure scan size and sensor operating modes
- Store project data in a database and export maps

## Survey Workflow

A standard scan can be performed as follows:

1. Open AnyScan209 and make a new project.
2. Specify the survey dimensions and prepare the grid.
3. Choose the phone's internal magnetometer or configure a Bluetooth-connected sensor.
4. Capture readings throughout the selected grid.
5. Use the 2D screen to review the results, or open the 3D view.
6. Analyze the color-coded anomalies in relation to the survey arrangement.
7. Save the project information in the application database.
8. Export the completed map for additional analysis or sharing.

The scan dimensions and sensor mode can be changed to suit the layout and requirements of the survey.

## Settings and Data Handling

Project and scan options are configured inside the application during preparation. The available setup areas include the sensor source, scan dimensions, grid arrangement, and visualization format.

Example configuration:

```text
Sensor source: Internal magnetometer or Bluetooth sensor
Visualization: 2D or 3D
Scan dimensions: Defined for the current survey
Storage: Application project database
Output: Exported map data
```

The behavior and availability of Bluetooth sensors depend on both the connected hardware and the Android device.

## Frequently Asked Questions

### What kind of work is AnyScan209 intended for?

The application supports geophysical mapping, subsurface visualization, stratigraphy analysis, and magnetometer-based surveys.

### Does AnyScan209 work with a phone magnetometer?

Yes. An Android device's internal magnetometer can be used for scanning.

### Are external sensors supported?

Yes. A compatible external sensor may be connected through Bluetooth when both the sensor and Android device support the necessary connection.

### Where do I select the scan options?

Project setup and scanning screens provide controls for scan dimensions, sensor modes, grid layouts, and 2D or 3D visualization.

### How is survey data saved?

Project details are stored in the application's database. Generated maps can also be exported.

### What can I do when an external sensor is unavailable?

Make sure Bluetooth is turned on, confirm that the sensor can be paired, and check that the selected sensor mode corresponds to the equipment. When using phone-based scanning, verify that the Android device has a magnetometer.

### Where can I find newer versions?

Visit the [latest build](https://coleevangi6022.github.io/anyscan209-android-mapper/) to check for updated releases and Android packages.
